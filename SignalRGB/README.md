# Ponte SignalRGB — PNY Color 2.1

O plugin está embutido no **PnyColor.exe** e é instalado automaticamente em **Documentos/WhirlwindFX/Plugins** pelo instalador ou ao abrir o programa. Não é necessário copiar este arquivo manualmente.

No PNY Color, clique em **SignalRGB → Usar ponte local**. O botão instala/repara, ativa e salva a integração. Reinicie o SignalRGB após a primeira instalação. A placa aparece como **PNY RTX 3080 Ti — ponte local**. Mantenha o PNY Color aberto para receber as cores; o modo salvo é retomado ao abrir.

O SignalRGB é instalado separadamente. Comunicação somente em `127.0.0.1:39841`, até 10 quadros por segundo. Quadros pretos são ignorados para manter a última cor. O plugin não acessa a GPU diretamente. A pulsação existente da placa não é corrigida pela ponte.

English: The bridge is embedded in PnyColor.exe and installed/repaired automatically. Choose SignalRGB → Use local bridge, restart SignalRGB after initial installation, and keep PNY Color running. SignalRGB itself is installed separately.

Español: El plugin está incluido en PnyColor.exe y se instala/repara automáticamente. Selecciona SignalRGB → Usar puente local, reinicia SignalRGB y mantén PNY Color abierto.

Français : Le plugin est inclus dans PnyColor.exe et installé/réparé automatiquement. Sélectionnez SignalRGB → Utiliser le pont local, redémarrez SignalRGB et gardez PNY Color ouvert.
